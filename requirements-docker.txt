# Curated dependency set for the Docker image.

# WHY NOT requirements.txt: that file is a full venv freeze from the Windows
# dev machine -- it pins platform-specific builds and dev-only packages that
# bloat (or break) a Linux image build. This list is the actual runtime
# surface of the containerized services (API + UI + ranking).
#
# NOT included, by design:
#   - ollama client needs: resume tailoring talks to Ollama over HTTP
#     (host.docker.internal:11434); no Python package required.
#   - Node/docx: the Dockerfile installs Node (apt) and runs `npm ci` in
#     backend/resume_engine; no pip package is involved.
